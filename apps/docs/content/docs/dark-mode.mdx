Every semantic token has a dark value. Add the `dark` class to any element and everything inside it switches, including components that use shadcn variables.

```html
<html class="dark">
```

It also works on a single region. That is how the previews on this site can stay light inside a dark page and the other way around.

```html
<section class="dark bg-background">…</section>
```

## Plain CSS projects

Projects that import `variables-dark.css` can also use `data-theme="dark"`.

```html
<body data-theme="dark">
```

## A theme switcher

The switcher in this site's header offers three choices: Light, Dark and System. Offer all three. People who set a system preference expect it to be honored.

Apply the saved choice with a small script in `<head>`, before the page paints, so it never flashes the wrong theme.

## What changes in dark

Dark mode is built on CapTech Dark Grey, `#333f48`, the same color as light mode body text. Every neutral comes from its blue grey hue.

- **The page is Dark Grey.** Cards, popovers and the sidebar sit one step lighter (`#3c4a55`), and muted fills one step lighter again (`#465663`). Lighter means closer to you.
- **Primary actions use a light CapTech blue** (`#77b7f7`) with dark text. A dark blue fill would sink into a mid tone page.
- **Links, status text and chart colors are lighter**, so every text color stays above 4.5:1 on cards and on the page.
- **Shadows use a deep tone of the same hue** instead of black, a little stronger than in light mode, so layers stay visible.
