## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx
<AspectRatio ratio={16 / 9}>
  <img src="/workshop.jpg" alt="Journey mapping workshop" className="size-full rounded-md object-cover" />
</AspectRatio>
```

## Guidance

**Do**

- Use it for images, video and embeds whose size is unknown before they load.
- Pick one ratio per content type and reuse it across the page.

**Don't**

- Wrap text content in it. Let text set its own height.

## Accessibility

The component is a plain container with no semantics. Give images `alt` text and give embedded video captions.

## API

Takes a required `ratio` number, such as `16 / 9`, and every `div` prop.
