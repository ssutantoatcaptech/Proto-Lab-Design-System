## Guidance

**Do**

- Use for settings that apply right away.
- Name the setting, not the action: "Beta features", not "Turn on beta".

**Don't**

- Put switches in a form with a submit button. Use checkboxes.

## Accessibility

Announced as a switch with its on or off state. Connect a label with `htmlFor`.

## API

Accepts every Base UI Switch prop, including `checked`, `defaultChecked` and `onCheckedChange`. See the [Base UI reference](https://base-ui.com/react/components/switch).
