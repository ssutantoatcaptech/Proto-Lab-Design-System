```

```


## Guidance

**Do**

- Keep it to one or two words.
- Use the same badge for the same status everywhere.

**Don't**

- Rely on badge color alone. The word carries the meaning.
- Make badges look like buttons.

## Accessibility

Badges are plain text to assistive technology. If one is interactive, render it as a link with `render`.

## API

`variant`: `default`, `secondary`, `outline`, `destructive`, `ghost`, `link`.
