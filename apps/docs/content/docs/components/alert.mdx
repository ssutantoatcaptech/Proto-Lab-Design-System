## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert"
```

```tsx
<Alert variant="destructive">
  <AlertCircleIcon />
  <AlertTitle>Upload failed</AlertTitle>
  <AlertDescription>The file is over 25 MB. Compress it or share a link.</AlertDescription>
</Alert>
```


## Guidance

**Do**

- Say what happened and what to do next.
- Place the alert next to the thing it is about.

**Don't**

- Stack several alerts. Combine them or fix the cause.
- Use an alert for a success message that needs no action. Use a toast.

## Accessibility

Alerts render with `role="alert"` and are announced. Use them sparingly for that reason.

## API

`variant`: `default` or `destructive`. Add any Lucide icon as the first child.
