## Guidance

**Do**

- Use it for answers longer than one sentence, such as notes or feedback.
- Show a character limit before people reach it, not after.

**Don't**

- Use it for short, single line values. Use an input.
- Rely on the placeholder as the label. Add a visible label.

## Accessibility

Pair the textarea with a `Label` through `htmlFor` and `id`. Set `aria-invalid` and link the error text with `aria-describedby` when validation fails.

## API

Accepts every native `textarea` prop. It sizes to its content with `field-sizing`, starting from a minimum height.
