## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

```tsx
<ToggleGroup variant="outline" spacing={0} defaultValue={["board"]}>
  <ToggleGroupItem value="list" aria-label="List view"><ListIcon /></ToggleGroupItem>
  <ToggleGroupItem value="board" aria-label="Board view"><KanbanIcon /></ToggleGroupItem>
</ToggleGroup>
```

## Guidance

**Do**

- Use it to switch views or apply formatting where the current choice should stay visible.
- Set `spacing={0}` to join the items into one control.

**Don't**

- Use it to navigate between pages of content. Use tabs.
- Use it for a long list of options. Use a select or checkboxes.

## Accessibility

Arrow keys move focus between items, and each item reports its pressed state. Icon only items need an `aria-label`, and the group needs one too.

## API

`ToggleGroup` takes `value` and `defaultValue` as arrays, `onValueChange`, `multiple`, `variant`, `size`, `spacing` and `orientation`. Each `ToggleGroupItem` needs a `value`. See the [Base UI reference](https://base-ui.com/react/components/toggle-group).
