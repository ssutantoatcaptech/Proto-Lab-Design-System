Proto-Lab uses two icon sets with different jobs. Mixing them up is the most common mistake.

## Interface icons: Lucide

Use [Lucide](https://lucide.dev) for anything functional: buttons, menus, inputs, status, navigation. Lucide icons inherit the text color and size with the text.

```tsx
import { PlusIcon } from "lucide-react"

<Button><PlusIcon /> New project</Button>
```

| Size | Use |
|---|---|
| 16px | Inside buttons, inputs and menus (the default) |
| 20px | Standalone icon buttons and toolbars |
| 24px | Navigation and empty states |

## Illustrative icons: CapTech

The 162 CapTech icons are two color illustrations at 48px. Use them for empty states, section headers and callouts about practices, values and ERGs.

<Callout variant="warning" title="Never use CapTech icons as interface icons">
They can't inherit color, don't scale below 32px, and read as decoration. Never put them in buttons, inputs, menus, tabs, badges or navigation.
</Callout>

### Install

Install every icon, or just one category.

<InstallCommand args="add @proto-lab/captech-icons" />

<InstallCommand args="add @proto-lab/captech-icons-practice-areas" />

Categories: `general`, `practice-areas`, `core-values`, `core-competencies`, `ergs`. Files land in `components/captech-icons/`.

### Use

```tsx
import { RocketLaunchIllustration } from "@/components/captech-icons/general"

<RocketLaunchIllustration size={64} />
<RocketLaunchIllustration size={64} title="Launch readiness" />
```

| Prop | Default | Notes |
|---|---|---|
| `size` | `48` | `32`, `40`, `48`, `64` or `96`. Never smaller than 32. |
| `tone` | `"duotone"` | `duotone`, `monotone`, `greyscale` or `inverse`. See below. |
| `title` | none | Gives the icon an accessible name. Leave it out when the icon is decoration next to text that says the same thing. |

Every icon name ends in `Illustration`, so it reads as one in code review.

### Tones

Four brand color modes, defined in `tokens/iconography.json`. Use the gallery's Tone switch to preview each one on the background it is made for.

| Tone | Colors | Use on |
|---|---|---|
| `duotone` | CapTech Blue and Yellow | Light and dark pages. The default. |
| `monotone` | CapTech Blue and Blue 30% | Light backgrounds where Yellow would compete |
| `greyscale` | Dark Grey and Dark Grey 30% | Light, neutral contexts |
| `inverse` | White and White 50% | Dark Grey, CapTech Blue and photography |

```tsx
<section className="bg-primary p-8">
  <CxCustomerExperienceIllustration tone="inverse" size={64} />
</section>
```

### Color and dark mode

Duotone reads `--illustration-primary` and `--illustration-accent`, so it follows the theme. In dark mode the blue lightens to brand 120, the same light blue as dark mode buttons, so icons read clearly on Dark Grey. The other tones are fixed brand colors and don't change with the theme. Without the Proto-Lab theme, duotone falls back to the brand hex values.

The SVGs in `icons/` stay the source. `npm run icons:build` regenerates the components, and fails if an SVG uses any color other than CapTech Blue or Yellow.
