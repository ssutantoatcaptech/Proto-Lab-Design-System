## Guidelines

| Element | Radius | Class |
|---|---|---|
| Buttons, inputs, menu items | 4px | `rounded-md` |
| Popovers, menus | 6px | `rounded-lg` |
| Cards, dialogs | 8px | `rounded-xl` |
| Avatars, pills | full | `rounded-full` |

Nested corners should get smaller toward the inside.
