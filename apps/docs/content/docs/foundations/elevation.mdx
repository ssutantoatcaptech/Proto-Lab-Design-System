Each level combines an ambient shadow and a key shadow. Dark mode uses stronger shadows because dark surfaces hide them.

<ElevationScale />

## Guidelines

- Resting cards sit at 2. Raise to 8 on hover only if the whole card is clickable.
- Menus and popovers use 4 to 16. Dialogs use 28 or 64.
- Don't stack shadows to make something stand out. Use elevation to show layering, not importance.
